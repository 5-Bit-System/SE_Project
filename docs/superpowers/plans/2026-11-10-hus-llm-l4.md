# HUS LLM L4 Implementation Plan

**Goal:** One active Q&A rewrite per process, immediate canonical fallback when
busy, and an independent, disclosed UI opt-in with truthful result/fallback labels.
**Architecture:** A module-scoped nonblocking lock surrounds the adapter invocation
in L2, including server-injected adapters, and releases in finally. The config
endpoint exposes only an availability boolean. UI keeps consent in tab memory,
sends rewrite permission only when checked/available, and resets it with F3 consent.
**Tech Stack:** Existing Python/threading/FastAPI, plain HTML/CSS/JS, pytest,
Playwright and Node tests. No new dependencies.
**Spec:** User-selected L4 row and ../specs/2026-11-10-hus-rag-gemini-design.md.
**Execution:** Native on `hus-llm-rag`; no commit/push, deployment, live provider
calls or edits to the private .env/default enable flag.

## Constraints / review focus

- Gate only adapter work after both consent/source/config gates; RAG can still
  answer requests while a provider call is pending. No wait queue or automatic retry.
- One Q&A adapter invocation per process, shared across requests/instances; no
  cross-process or direct standalone-client concurrency guarantee is claimed.
- Release the slot on success, schema rejection, timeout/HTTP failure and canonical
  exception. Client abort must not free a slot while provider work is still running.
- HTTPX 20s per phase remains; no total-20s deadline, stream/retry/redirect changes.
- Preserve canonical answer/facts/citations, existing budgets and L2 flag-off shape.
- Expose optional safe numeric HTTP status for quota UI; no provider body or secret.
- UI is off initially and independent of F3 permission; config unavailable disables
  only rewrite. Never accept permission from a catalog request or persisted storage.
- UI disclosure: question and selected evidence go to Google; history is not sent.
- Mark AI only when backend `generation.used === true` and the request opted in.
  Otherwise label canonical fallback for answered RAG when opt-in was requested.
- Keep AI-reference source labels, textContent rendering, major reset and late-response
  epoch guard. Explicitly test delayed responses that ignore AbortController.
