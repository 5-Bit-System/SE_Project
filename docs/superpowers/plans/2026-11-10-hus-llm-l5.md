# HUS LLM L5 Implementation Plan

**Goal:** Paired RAG-original / Gemini-3.5-Flash-Lite content evaluation with frozen
retrieval, exact-response-bound AI review and separately counted use/fallback.
**Architecture:** Prepare immutable canonical answers once using lexical retrieval;
rewrite those exact snapshots through the existing L2/L3 adapter. Capture provider
status/model/usage even for rejected output. Replay and semantic scoring use cached
files only. No production behavior, retrieval, prompt or budget tuning.
**Tech Stack:** Existing Python/httpx/pytest/FastAPI tooling, no new dependencies.
**Spec:** User-selected L5 row; existing HUS RAG/Gemini design and L1-L4 contracts.
**Execution:** Native on hus-llm-rag. No commits/push/deploy/default activation.

## Measurement decisions

- A is canonical RAG, B is the existing Gemini 3.5 Flash-Lite pipeline. Two models
  are not necessary to establish whether rewrite improves the current baseline.
- Select by frozen gold/request fields before generation: two cases per major and
  family (24 positive); eight missing/OOS/F3-consent controls, two clarification
  contracts and two explicitly AI-authored basic-chat controls. Exposed dev, not holdout.
- Cap live calls at 24; minimum 5 seconds between provider attempts, no retry.
  Stop further outbound calls after quota 429; report unattempted eligible cases.
  CLI requires explicit live mode and server env file. Never edit private .env,
  print keys, change billing or automatically switch provider/model.
- Pin source release/assets, original pack manifests/inputs, runtime/evaluator code,
  environment, model/base URL and canonical inputs before collection; recheck after.
- B receives the exact effective request/answer from A, without another retrieval.
  Save A latency, incremental B latency, provider latency, tokens/errors/prompt hash.
  No production SLO, total-20s deadline or cost-free guarantee is inferred.
- Raw provider body is never saved. Record safe actual model/usage/status when
  observable, including rejected output; unknown stays unknown.
- Review exact A/B response + selected citations + frozen target, with explicit
  entailment/completeness/readability notes; reviewer AI, human count zero. Structural
  checks, fallback and a successful HTTP call never become a semantic pass.
