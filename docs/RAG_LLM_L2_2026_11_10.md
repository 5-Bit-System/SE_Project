# L2 — Quyền và hợp đồng diễn đạt HUS

Ngày 10/11/2026, local trên `hus-llm-9router-gemini`; không commit/push/deploy.
Người dùng chọn riêng hàng L2 trong kế hoạch, gồm F1/F2/F3 và giữ dữ kiện F2.

## Hành vi

`HUSQuestion.allow_llm_rewrite` là strict boolean mặc định false, độc lập với
quyền `allow_generated_reference`. Giá trị string, số, null hoặc container bị từ chối.
Trường mới được bỏ khỏi serialization request khi false để giữ request cũ.

| Điều kiện | Kết quả |
| --- | --- |
| Người dùng hoặc server tắt | Response đúng ba trường cũ; không thêm `generation: null`, không đọc toàn bộ cấu hình LLM hoặc gọi adapter. |
| Cả hai bật, basic chat | Giữ reply, metadata `basic_chat`, không gọi adapter. |
| Chưa answered/cần làm rõ/không có thông tin | Giữ reply, metadata `not_answered`, không gọi adapter. |
| Answered nhưng không có citation | Giữ reply, metadata `no_sources`. |
| F3 chưa được phép | Không gọi adapter; guard độc lập với quyền diễn đạt. |
| Đủ quyền nhưng cấu hình thiếu/sai | Giữ reply, metadata `configuration`; không đưa key/lỗi provider ra response. |
| Đủ quyền nhưng chưa có L3 | Giữ reply, `pipeline_unavailable`; không gửi HTTP tới provider. |
| Adapter thành công | Chỉ thay reply cấp chat, `generation.used=true`; `hus_answer` giữ nguyên. |
| Adapter trả sai hợp đồng hoặc lỗi | Giữ reply canonical, metadata lý do ổn định; không báo model đã dùng thành công. |

`generation` gồm `used`, `requested_model`, `model` (do adapter báo nếu thành công),
`fallback_reason`. Model yêu cầu và model trả về được tách riêng. Lỗi canonical
vẫn fail closed, không bị biến thành fallback LLM.

## Hợp đồng adapter

`app/hus/llm/contracts.py` định nghĩa context và các kết quả; `generation.py` thực
hiện quyền/dispatch/fallback. `chat(..., rewriter=...)` là điểm nối do server kiểm
soát, không thể truyền callable/URL/model/key qua payload HTTP.

Context chỉ có bản sao sâu của request hiệu lực, đáp án canonical và model yêu cầu.
Adapter không nhận key, account, transcript hoặc toàn bộ lịch sử. Việc sửa nested
facts/citation/review trong context không ảnh hưởng dữ liệu response gốc.

F1/F3 dùng `HUSTextRewrite`; cảnh báo canonical được giữ trong reply hiển thị.
F2 chỉ dùng `HUSF2Presentation` với style cố định; backend chèn nguyên đáp án F2
gốc, gồm null/unknown/conflict/unresolved, giá trị và cảnh báo. Free text F2 bị từ chối.
Mọi kết quả được kiểm lại bằng schema từ dữ liệu dump, không tin việc object đã có
đúng kiểu vì `model_copy`/`model_construct` có thể bỏ validation.

## Phạm vi chưa triển khai

L2 **không đăng ký pipeline L3 mặc định**, không dựng prompt, không gọi model hay
tự chứng minh entailment. Vì vậy bật cờ LLM hiện chưa tạo câu trả lời Gemini từ RAG;
API giữ bản trích nguồn với lý do `pipeline_unavailable`. L3 sẽ cung cấp adapter
đã kiểm đầu ra; UI/giới hạn thuộc L4. Không sửa retrieval, nguồn, index/model cache,
baseline/gold hoặc receipt lịch sử. Default lexical và LLM off được giữ.
