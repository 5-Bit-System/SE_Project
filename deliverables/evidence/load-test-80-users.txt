4.3. Test Environment & Architectural Considerations:
  - Benchmark Environment: Windows 10 (AMD64, 16 logical cores, 15.7 GB RAM).
    * Target DB: PostgreSQL 16 on loopback TCP 127.0.0.1:5433 (via HUS_TEST_DATABASE_URL).
    * In-process ASGI transport via Starlette TestClient.
  - Methodological Boundaries & Production Considerations (Qualitative):
    1. Network Transport: The in-process harness bypasses physical network transport, TLS handshake,
       and reverse proxy routing. In production, network round-trip time will add to end-to-end latency.
    2. Multi-Process Connection Pool Scaling: Each independent Uvicorn worker process instantiates its own
       SQLAlchemy QueuePool; uncoordinated horizontal scaling without external connection pooling (e.g. PgBouncer)
       risks exhausting PostgreSQL database connection limits.
    3. Advisory Lock Scope: Because pg_advisory_xact_lock('ai07_hus_catalog_publish') is currently a single
       global lock, review transactions are strictly serialized across the entire database.
       To scale concurrent throughput across unrelated departments, the lock can be sharded by academic major.
